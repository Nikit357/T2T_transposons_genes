Transposable elements by class

All 3,709,429 RepeatMasker-annotated transposable elements in T2T-CHM13v2.0, split into one subtrack per class. Item names are subfamilies and item scores are RepeatMasker divergence (substitutions per 1000 bp, observed range 0-480; higher means older).

Source

Built by revision_G3/12_build_trackhub.sh from the T2T-CHM13v2.0 RepeatMasker annotation and NCBI RefSeq gene annotation used throughout Nikitin (2026), github.com/Nikit357/T2T_transposons_genes. Colours match the TE class palette used in the paper's figures.
