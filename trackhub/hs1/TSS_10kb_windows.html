TSS 10 kb neighbourhoods

The 38,704 transcription start site neighbourhoods (5 kb either side of each TSS) that define proximity throughout the paper, covering 28,738 genes. Genes with several annotated TSS contribute several windows. A small number of windows are clipped where a TSS lies within 5 kb of a chromosome end.

Source

Built by revision_G3/12_build_trackhub.sh from the T2T-CHM13v2.0 RepeatMasker annotation and NCBI RefSeq gene annotation used throughout Nikitin (2026), github.com/Nikit357/T2T_transposons_genes. Colours match the TE class palette used in the paper's figures.
